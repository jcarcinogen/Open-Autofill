Privacy

Open Autofill is free, local, and offline. There is no account and no cloud copy of your answers.

What we store

Form answers you type (email, name, address, Instagram, Official Rules checks, and extra per-site fields) are saved in this browser profile only using Chrome’s local extension storage.

What we never do

No servers. No analytics. No crash reports. No accounts. No sync. We do not sell or share your data, because it never leaves your computer unless you export a JSON backup file.

Permissions

The extension can read pages so it can fill forms. It does not send those pages anywhere.

Your backups

Export JSON writes a file to your computer. Import reads a file you choose. Neither step uploads anything.
