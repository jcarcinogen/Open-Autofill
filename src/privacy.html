Privacy

Open Autofill is free, local, and offline. There is no account and no cloud copy of your answers. Websites you fill may receive the values you put in their forms.

What we store

Form answers you type (email, name, address, Instagram, Official Rules checks, and extra per-site fields) are saved in this browser profile only using Chrome’s local extension storage.

Open Autofill uses this information only to remember and fill form fields at your direction. Values remain until you edit them, clear them, forget a site, reset extension storage, or uninstall the extension.

What we never do

No servers. No analytics. No crash reports. No accounts. No sync. We do not sell or share your data. The extension does not upload answers. Websites you fill may receive the values you put in their forms. A JSON backup stays on your computer unless you copy that file yourself.

Permissions

The extension can read pages so it can fill forms. It does not send those pages anywhere.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Page and form data is used only for form memory and autofill.

Your backups

Export JSON writes a file to your computer. Import reads a file you choose. Neither step uploads anything.
