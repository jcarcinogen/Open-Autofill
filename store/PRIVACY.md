# Open Autofill — Privacy Policy

Last updated: September 6, 2026

Public HTTPS copy: https://jcarcinogen.github.io/Open-Autofill/privacy.html

Open Autofill is a free browser extension. Form answers are stored in this Chrome profile. **The extension does not send your answers to the developer or to any Open Autofill server.** Website scripts can read autofilled values before submission. Local-only storage does not prevent that disclosure.

## Data we store

- Identity fields you enter (for example email, name, address, phone, social handles)
- Per-website extra fields, field labels, and Official Rules / I-agree checkboxes you have used
- Website origins (scheme, hostname and port), form/field identifiers, and ignored hostnames
- Settings, cleared-answer markers, preserved legacy records, and a local pre-restore recovery snapshot

This data is stored in **Chrome local extension storage on this computer / profile**. It is not encrypted beyond whatever Chrome already does for extension storage.

Open Autofill uses this information only to remember and fill form fields at your direction. Remembered values remain until you edit them, clear them, forget a site, reset extension storage, or uninstall the extension.

## Data we do not collect

Open Autofill does **not**:

- Create an account
- Talk to a backend of ours
- Sync to the cloud
- Use analytics, ads, crash reporting, or telemetry
- Sell, rent, or share your information with anyone

There is no remote server to share with.

## Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Open Autofill uses locally processed page and form data only to provide its form-memory and autofill features.

## JSON backup

Export downloads a versioned, timestamped JSON file. Import validates and previews a replacement before you confirm it, and saves a local pre-restore recovery snapshot for undo. Backups contain personal answers in readable text; store them privately. Those files are yours. We never receive them.

## Permissions

Open Autofill can run on websites so it can fill forms. Page contents are processed on your device only.
